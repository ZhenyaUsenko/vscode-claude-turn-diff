# Working in this repo

Read `TECHNICAL.md` before changing anything under `src/`. It records why the
code is shaped the way it is, and its `## Naming` section defines the vocabulary
this project uses for files, directories, paths, names and contents — one name
per entity, one entity per name.

Verify with `npm test`, which runs the whole suite against a temporary `HOME`
and a stubbed `vscode` module.

Don't create memory files for this project.
